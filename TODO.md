**How an item is written.** One short paragraph: the title, the date it was filed, its severity,
the issue it belongs to, what is open, and the measured evidence that it is open. A measurement
episode, a review history, a rejected alternative, or a disclosure goes to a comment on that
issue, and the item links to the comment.

**How a finished item is recorded.** The pull request that finishes it removes it from this file.
That pull request's description, or a comment on the issue the item belongs to, carries the
record: what closed it, the evidence, and the measured figures with the commit they were taken
at. The commit message names the item's title and the issue or pull request number, so
`git log -S '<title>' -- TODO.md` finds it. An item is also removed when it turns out never to
have been a task. **An item with no issue** records its evidence in the pull request that finishes
it and nowhere else; if it is large enough to need a comment before then, file the issue at that
point rather than growing the item here.
