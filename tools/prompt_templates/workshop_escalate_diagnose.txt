Decision criteria: choose the SHALLOWEST rollback that can actually fix the root cause. A code defect (the generated source is wrong) is `action="retry"` with `target_phase="generate"`. A defect in the human-authored spec, or one no phase can fix, is `action="fail_closed"`.
